# EdgeML Gesture Recognition (Magnetometer) 

Это пет-проект, в котором я с нуля собрал пайплайн для распознавания пространственных жестов с помощью смартфона. Никаких готовых датасетов и тяжеловесных библиотек на клиенте — только хардкор: сбор сырых данных напрямую из памяти датчика, обучение легковесной CNN и кастомный инференс.

Проект зафиксирован как успешный MVP и отлично показывает себя на бинарной классификации (свайпы).

## Что внутри (Технический стек)

1. **Сбор данных (C + Termux + Flask):** Нативный C-демон использует API Android NDK (`ASensorManager`) для опроса магнитометра (100 Гц) в обход виртуальной машины Java, что исключает задержки от сборщика мусора. Разметка и сбор датасета идут через локальный Flask-сервер со звуковой синхронизацией и отрисовкой на `Chart.js`.
2. **Аугментация (Time Series):** Применены физически обоснованные искажения: сглаженный гауссовский шум для имитации микротремора и термального дрейфа датчика. Временные сдвиги реализованы через *Edge Padding*, чтобы исключить артефакты и разрывы на границах сигнала.
3. **Обучение (PyTorch):** Написана кастомная 1D-CNN (`EdgeCNN_v4`, ~15.7k параметров). Разделение на *train/val* сделано через `GroupShuffleSplit` (группировка по исходному жесту), что полностью исключает утечку данных (*Data Leakage*) при аугментации.
4. **Инференс (NumPy):** Предикт переписан на чистый `NumPy` без использования TFLite/ONNX. Вручную реализованы математика слоев `Conv1d`, `BatchNorm1d` и `MaxPool1d`. Модель работает в реальном времени с динамической калибровкой фонового шума.## Демонстрация

## Результаты R&D и Pivot на V2

Текущий MVP уверенно справляется с бинарной классификацией (Одинарный / Двойной клик с магнитом) и фильтрует фон. Вся программная инфраструктура пайплайна (нативный C-демон, Flask-сервер, 1D-CNN и NumPy-инференс) работает стабильно и полностью валидирована.

Однако тестирование выявило концептуальные ограничения самого магнитометра для детекции тапов:
* **Нецелевая физика:** Клик — это механическое ускорение корпуса. Чтение контакта через возмущения магнитного поля неизбежно собирает фоновый электромагнитный шум помещения.
* **Нехватка степеней свободы:** Датчик путает паттерны, так как по его осям математически невозможно отличить поворот устройства от линейного смещения.

**Стратегия развития:** 
Готовый ML-пайплайн переносится на профильное железо — **акселерометр**. Это обеспечит работу с чистыми пиками механического ускорения, сведет ложные срабатывания к абсолютному нулю и позволит отказаться от использования магнита на пальце.
